# Sistem Panca Indera Pada Manusia

Makalah digital yang membahas tentang sistem panca indera pada manusia, diajukan untuk memenuhi mata pelajaran IPA. Disusun oleh Sakilah Mutia Zahra.

## Fitur Utama
- Halaman Sampul Makalah dengan logo sekolah Ikhlas Beramal.
- Penjelasan komprehensif mengenai 5 indera: Penglihatan, Pembau, Pendengar, Pencecap, dan Peraba.
- Ilustrasi placeholder anatomi di samping kanan penjelasan untuk setiap indera (tata letak responsif).
- Penjelasan gangguan dan kelainan umum, serta saran pemeliharaan kesehatan panca indera.

## Teknologi
- Flutter
- Dart
- Desain Responsif (Mendukung Desktop, Web, dan Mobile)

## Cara Menjalankan
1. Pastikan Anda telah menginstal Flutter.
2. Jalankan `flutter pub get`.
3. Jalankan `flutter run` untuk memulai aplikasi di emulator atau browser.
